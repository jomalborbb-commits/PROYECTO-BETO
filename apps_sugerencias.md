# Sugerencias para crear apps — Kotlin y Dart (Flutter)

Enlaces oficiales para empezar a crear apps de celular. No reemplazan tu sistema web actual; son para el día que quieras hacer una app aparte.

## Kotlin (apps Android)
- Descargar Android Studio (el programa para crear la app): https://developer.android.com/studio
- Aprender Kotlin (documentación oficial): https://kotlinlang.org/docs/home.html
- Probar Kotlin en el navegador, sin instalar nada: https://play.kotlinlang.org
- Curso gratis de Google para hacer tu primera app (Android Basics con Compose): https://developer.android.com/courses/android-basics-compose/course
- Compose (la forma moderna de dibujar pantallas): https://developer.android.com/compose

## Dart y Flutter (Android e iOS con un solo código)
- Instalar Flutter (incluye Dart): https://docs.flutter.dev/get-started/install
- Aprender Dart: https://dart.dev/language
- Probar Dart en el navegador, sin instalar nada: https://dartpad.dev
- Tu primera app en Flutter: https://docs.flutter.dev/get-started/codelab
- Paquetes para tu app (por ejemplo, leer Excel o guardar datos): https://pub.dev

## Cuál conviene
- **Kotlin:** si solo quieres Android y aprovechar bien el teléfono.
- **Dart con Flutter:** si quieres una sola app para Android e iOS (y hasta web y escritorio). Para un sistema como el de ventas, suele ser la opción más práctica.

Si tu computadora es modesta, Android Studio pesa bastante: empieza probando en DartPad o Kotlin Playground, sin instalar nada.
